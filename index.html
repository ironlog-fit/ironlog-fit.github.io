Runs a small open-source model entirely in your browser. Uses your GPU (WebGPU) when available for speed; if your device can't do that, it automatically falls back to a slower CPU model instead — either way, nothing is sent anywhere, no account or key needed, and it keeps working offline once downloaded. It's noticeably less capable than the cloud option — good for quick tips and rough estimates, not for anything you'd trust blindly.

About

IronLog is an independent, self-hosted personal tracker. It was inspired by the feature set of fitness apps like EliteEngine (workout logs, habit tracking, macro tracking, XP ranks, an AI coach) but shares no code, design assets or branding with them.Complete code is Open Source you can check and verify it.
